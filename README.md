# VoteApp — Python

A desktop voting application built in Python with a graphical user interface. Built as a school project and deployed for actual school use — recognised with the **Effort and Effectiveness Award**.

## Features

- Graphical UI (desktop application)
- Candidate registration and management
- Vote casting with duplicate-vote prevention
- Live vote counter
- Result tallying and display

## How to Run

**Requirements:** Python 3.x

```bash
# Clone the repo
git clone https://github.com/darshfi/VoteApp-using-python.git
cd VoteApp-using-python

# Run the app
python VotingApp.py
```

> A pre-built Windows executable is also available in the `build/App` folder.

## Project Structure

```
VoteApp-using-python/
├── VotingApp.py          # Main application with GUI
├── VotingApp(old).py     # Earlier console version
├── vote_counter.py       # Vote counting logic
└── build/App/            # Compiled Windows executable
```

## Tech Stack

`Python` `Tkinter (GUI)` `File I/O`
